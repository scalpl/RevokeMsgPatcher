# 👀微信/QQ/TIM防撤回补丁
适用于 Windows 下 PC 版微信/QQ/TIM的防撤回补丁。**支持微信/QQ/TIM**，其中微信能够选择安装多开功能。

本分支已修复微信 **4.1.15.12 x64** 多开失效及旧规则误改语音输入锁的问题，详见[修复说明与回归测试](docs/weixin-4.1.15.12.md)。
